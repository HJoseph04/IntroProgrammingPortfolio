# Datatype Variables

Datatypes are basically labels that tells your computer what kind of information you want to store and run. 
It matters because the computer has to know how much memory you're saving up and what kind of operations are allowed on said space.
For example, you can add more than one integer together in one go, but you can't do the same thing for a string unless it's converted to something.
And be careful what type you use, because if you mishandle your datatypes, your program might either crash or it gives you the results you don't really want displayed. Make sure you know what type you're using so that you will both understand what you're actually programming, and that you can avoid bugs in your code  so that your program runs smoothly.
But overall, datatypes are the gateway for how a program is organized and how it handles information.
