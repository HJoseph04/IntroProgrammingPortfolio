# IF Statement

An IF statement is a way for a program that makes decisions, think of it as like "if that deal is made with or between this and this, then this happens."
When that program reaches said statement, it evaluates that condition and only enters the braces if that statement is true.
It lets the program feel like security checkpoints either at the border or at an airport in this case, though it depends on the values you're working with.
It sounds simple enough, until you get to the parts where multiple conditions are plugged in or if you're nesting if statements to handle more complex logic, especially with Else and Else If. Though you can also use these statements to fulfill any boolean logic you want out of the way too.
Overall, the IF statement is what gives your program the ability to do some choices and behave with some intelligence instead of just kamikazee'ing through these gates.

SYNTAX:
if (condition)
{
 // insert code here
}
