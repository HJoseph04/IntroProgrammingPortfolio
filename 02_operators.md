# Operators

Operators are symbols that let you tell the computer what you want to perform between two or more integers.
There are two types of operators, the first of them (Basic Operators) are if you want to work the program the same way a calculator does. 
The other set (Comparison Operators) follow boolean logic, but these are more conditional values to see if this or more conditions are satisfied.
When you run the program, it checks on the operators first, and then uses the result to see what to do next. Yes it's a bunch of symbols, but once you understand how each of them works, then your flow of the code will be much easier to follow.
Overall, operators are like puzzle pieces that control the logic and math behind nearly every line.



- Basic Operators

+ Sum
- Difference
* Product
/ Division
% Modulo

- Comparison Operators

< Strictly Less Than
> Strictly Greater Than
>= Greater Than OR Equal To
<= Less Than OR Equal To
== Strictly Equal To
!= NOT Equal To

- Multi-Use Operators (for multiple conditions)

  || OR
  && AND
