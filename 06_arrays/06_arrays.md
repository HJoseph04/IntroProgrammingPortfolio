# ARRAYS

An array is something you do that stores a group of values under one index (if you're doing random numbers, it doesn't have to be in order.)
Instead of creating seperate values, why not put them all into this one array to make things easier? Especially if you're dealing with long lists and in case you don't even know all the variables.
When you run your program, it uses these index values to jump directly to the position you want, kinda similar to a game of hopscotch.
If you want to do grades, names and scores, this is the perfect thing for you because you can just loop them in one shot instead of dealing with each value manually.
Overall, arrays give your code an efficient way to keep and manage sets of data.
